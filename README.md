## 📖 Overview
<a id="overview"></a>

**All My Software** is a powerful tool designed for Windows that allows you to catalog and organize all the applications installed on your computer. With the **latest version**, you can create a comprehensive database that helps you keep track of important details such as license expiration dates, developer information, and program pricing. 

This software is continuously updated to provide users with the **full functionality** needed to maintain a well-organized system. **All My Software** is your go-to solution for efficiently managing your applications and ensuring you have easy access to essential information.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Comprehensive Cataloging** — Create a detailed database of all installed programs, including their license expiration dates and pricing.
- **Registry Search** — Automatically scans the operating system's registry to locate all installed applications, displaying them in an organized list.
- **Detailed Information** — Fill in various fields for each application such as price, website, registry key, developer, and personal notes.
- **Quick Search Feature** — Easily find the application you need, even among a large number of installed programs.
- **Export to Excel** — Export your application database for printing and further analysis.
